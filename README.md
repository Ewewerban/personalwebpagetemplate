# YOURNAME - Personal Website Template

Free single-file portfolio template for GitHub Pages.
Orange / glass style. No build needed. Just 1 file: `index.html`

## How to use - 3 steps

### STEP 1: Create repo on GitHub
1. Go to github.com -> New Repository
2. Name it EXACTLY like this:
   `YOURNAME.github.io`
   Example: if your name is `john`, repo must be `john.github.io`
3. Set it to Public
4. Click Create

### STEP 2: Paste the code
1. In that repo click `Add file` -> `Create new file`
2. File name: `index.html`
3. Copy ALL code from `index.html` in this template and paste it there
4. Click `Commit changes`

### STEP 3: Open your site
Wait 1-2 minutes, then open:
`https://YOURNAME.github.io`

Done. Your site is live.

## WHERE TO CHANGE WHAT - Search in index.html for CHANGE HERE

| Search this in code | What to change |
| :--- | :--- |
| `YOURNAME` | Your nickname. Change everywhere. Example: `john` |
| `YOUR_TAGLINE` | Your job. Example: `Game Developer` |
| `YOUR_DISCORD_LINK` | Your Discord invite. Example: `https://discord.gg/xxxx` |
| `YOUR_MAIN_PROJECT_NAME` | Your main project name. Example: `My Game` |
| `YOUR_MAIN_PROJECT_DESC` | Description of your main project |
| `YOUR_MAIN_PROJECT_LINK` | Link to your main project |
| `YOUR_MAIN_PROJECT_STATUS` | Status: `Active` / `In Progress` / `Done` |
| `YOUR_YOUTUBE_SUBS` | Your YouTube subs number |
| `YOUR_VIDEO_COUNT` | Your video count |
| `YOUR_SOCIAL_LINK` | Links for Bluesky, itch.io, X, YouTube, Twitch, TikTok, GitHub |
| `YOUR_YEAR` | Year in footer, example: `2026` |

Tip: In VS Code / GitHub press `CTRL + F` and search `CHANGE HERE` - you will find all places.

## How to change colors?
In `<style>` at top, search:
`#f97316` = main orange. Replace with your color.
Example blue: `#3b82f6`

## Files
- `index.html` = whole website, only 1 file needed
- `README.md` = this file
